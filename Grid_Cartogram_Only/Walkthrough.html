01 / DATA FOUNDATION

Dataset & Processing Details

This project uses the San Francisco film location dataset from DataSF (Film Locations in San Francisco).

~3,000+ Total Location Records
400+ Unique Film Titles
11 City Districts

Data Pipeline Details

  • Data Cleaning: Extract the Release Year, trim extra spaces, and convert Supervisor District into clean string IDs (e.g., `"1"` to `"11"`).
  • Data Filtering: Keep only valid records that belong to San Francisco's 11 supervisor districts. Invalid entries are excluded.
  • Data Aggregation (Rollup):
    - Record Count: Use d3.rollup grouped by district to count total filming locations.
    - Movie Count: Use a hash key JSON.stringify([d.Title, d.year]) with a Set to count unique movie titles in each district.

How the Cartogram is Built

Using the D3.js pipeline, the visualization is built in four simple steps:

Step 2: Render Tiles with D3 Data Join

Bind data to create SVG <rect> squares and text labels, then move them into position using translate.

function drawMap(data) {
  const svg = d3.select("#chart");
  const tiles = svg.selectAll(".tile")
    .data(data, (d) => d.id)
    .join((enter) => {
      const g = enter.append("g").attr("class", "tile");
      g.append("rect").attr("width", 112).attr("height", 112).attr("rx", 2);
      g.append("text").attr("class", "district-label").attr("x", 14).attr("y", 24);
      g.append("text").attr("class", "count-label").attr("x", 14).attr("y", 68);
      return g;
    })
    .attr("transform", (d) => `translate(${38 + d.col * 124},${17 + d.row * 124})`);
  
  tiles.select("rect").transition().duration(250)
    .attr("fill", (d) => (d.count ? state.color(d.count) : "#e5e7df"));
  tiles.select(".count-label").text((d) => fmt.format(d.count));
}

Step 3: Color Scaling and Legend

Use d3.scaleSequentialSqrt to map location counts to color lightness, and draw a smooth scale legend.

state.color = d3
  .scaleSequentialSqrt(d3.interpolateRgb("#e5eed5", "#efacd5"))
  .domain([0, max]);

function legend(max) {
  const scale = d3.scaleSqrt().domain([0, max]).range([1, 349]);
  d3.select("#legend").append("svg")
    .selectAll("rect").data(d3.range(349)).join("rect")
    .attr("x", (d) => d + 1)
    .attr("fill", (d) => state.color(scale.invert(d + 1)));
}

Step 4: Bind Interactions

Add click selection and accessible keyboard controls (Enter/Space) to every district tile.

function events(selection) {
  selection
    .attr("tabindex", 0)
    .attr("role", "button")
    .on("click", (e, d) => choose(d.id))
    .on("keydown", (e, d) => {
      if (e.key === "Enter" || e.key === " ") {
        e.preventDefault();
        choose(d.id);
      }
    });
}
